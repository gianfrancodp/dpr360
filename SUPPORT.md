# Support

Use GitHub Issues for reproducible bugs and feature requests.

Before reporting a processing failure:

1. run the built-in smoke test;
2. note the failing pipeline step and return code;
3. include the DPR360 version and Windows version;
4. describe the drone/capture mode without publishing sensitive metadata;
5. review any log before attaching it.

The current logger redacts local paths, GPS and camera identifiers by default, but logs should still be treated as potentially sensitive. Do not publish original DNG/TIFF files unless you explicitly intend to make them public.
